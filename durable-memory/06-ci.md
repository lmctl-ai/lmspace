# CI and releases

`.github/workflows/ci.yml` follows lmnum's pinned-action workflow. Five jobs build and test Linux x64, Linux arm64, macOS arm64, macOS x64 and Windows x64. Each installs lmscript from `@lmctl-ai/lmctl@0.2.419`, verifies dependency and SDK pins, builds, runs physics and DSL tests, checks signatures and the system-library policy, and uploads a platform binary.

The build step sets `LMSPACE_TEST_NETWORK=1` and `GITHUB_TOKEN` for install lookups. Core tests generate synthetic kernels; some gallery examples fetch their own public NAIF kernels or map data. Tag pushes build all platforms and run the release job only after all five succeed. The release checks that the binary version matches the tag before publishing all binaries and notices. Build jobs have read-only repository permissions; only the release job has contents write permission.

Windows checkout must keep LF bytes: `.gitattributes` prevents CRLF conversion of lock files, schema and the pinned SDK header. CRLF otherwise appends a carriage return to dependency commit IDs and breaks both Git fetch and content hashes.
