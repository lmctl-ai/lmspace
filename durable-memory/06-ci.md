# CI and releases

`.github/workflows/ci.yml` follows lmnum's pinned-action workflow. Five jobs build and test Linux x64, Linux arm64, macOS arm64, macOS x64 and Windows x64. Each installs lmscript from `@lmctl-ai/lmctl@0.2.369`, verifies dependency and SDK pins, builds, runs physics and DSL tests, checks signatures and static linking, and uploads a platform binary.

The build step sets `LMSPACE_TEST_NETWORK=1` and `GITHUB_TOKEN` for install lookups. No astronomy kernels are downloaded. Tag pushes build all platforms and run the release job only after all five succeed. The release checks that the binary version matches the tag before publishing all binaries and notices. Build jobs have read-only repository permissions; only the release job has contents write permission.
